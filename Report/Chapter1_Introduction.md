## 1.4 ความสำคัญและที่มาของปัญหา
ในปัจจุบัน ปัญหาภาวะซึมเศร้า (Depression) เป็นปัญหาสุขภาพจิตที่สำคัญระดับโลกและมีแนวโน้มเพิ่มสูงขึ้นอย่างต่อเนื่อง โดยองค์การอนามัยโลก (WHO) ระบุว่าโรคซึมเศร้าเป็นหนึ่งในภาระโรคสำคัญที่ส่งผลกระทบต่อสุขภาวะทางกาย จิตใจ และประสิทธิภาพในการดำเนินชีวิต อย่างไรก็ตาม บุคคลทั่วไปหรือบุคคลใกล้ชิดรอบข้างผู้เผชิญภาวะซึมเศร้ามักขาดความเข้าใจที่ถูกต้องเกี่ยวกับลักษณะอาการ สภาวะอารมณ์ และกระบวนการคิดของผู้ป่วย การสื่อสารด้วยถ้อยคำเพียงอย่างเดียวอาจไม่สามารถถ่ายทอดสภาวะ "อารมณ์ดิ่ง" ความว่างเปล่า หรือความหนักอึ้งในจิตใจได้อย่างชัดเจน

จากรายงานสถานการณ์สุขภาพจิตในประเทศไทย พบว่าประชากรกลุ่มวัยรุ่น วัยเรียน และวัยผู้ใหญ่ตอนต้น มีสถิติการเจ็บป่วยและเผชิญความเครียดสะสมสูงขึ้นอย่างมีนัยสำคัญ แต่สังคมยังคงมีภาพจำหรือตราบาป (Stigma) มองว่าภาวะซึมเศร้าเกิดจากความอ่อนแอ หรือการเรียกร้องความสนใจ ซึ่งส่งผลให้ผู้เผชิญภาวะนี้เลือกที่จะปกปิดปัญหา ถอนตัวออกจากสังคม หรือไม่กล้าเข้าสู่กระบวนการรักษาทางการแพทย์

จากสภาพปัญหาดังกล่าว คณะผู้วิจัยจึงมีแนวคิดในการประยุกต์ใช้เทคโนโลยีคอมพิวเตอร์และสื่อดิจิทัลเชิงโต้ตอบ (Interactive Digital Media) ในรูปแบบ "เกมเพื่อการเรียนรู้และจำลองประสบการณ์" (Educational Simulation Game) ภายใต้เทคนิคการนำเสนอแบบ 2.5 มิติ (2.5D) เพื่อจำลองสภาวะจิตใจ พลวัตความสัมพันธ์ในครอบครัว และแรงกดดันในโรงเรียน โดยเปิดโอกาสให้ผู้เล่นสวมบทบาทเป็นผู้เผชิญภาวะซึมเศร้า ได้สัมผัสถึงผลกระทบจากการเลือกตัดสินใจในการใช้ชีวิตประจำวัน ซึ่งจะช่วยเสริมสร้างความตระหนักรู้ ความเข้าใจที่ถูกต้อง และความเห็นอกเห็นใจ (Empathy) เพื่อนำไปสู่การอยู่ร่วมกันในสังคมอย่างเกื้อกูลและยั่งยืน

## 1.5 วัตถุประสงค์ของโครงงาน
1. **เพื่อเรียนรู้และประยุกต์ใช้องค์ความรู้ทางวิทยาการคอมพิวเตอร์:** ศึกษาและประยุกต์ใช้หลักการออกแบบเกม (Game Design) การเขียนโปรแกรมเชิงวัตถุ (Object-Oriented Programming: OOP) และการจัดการวงจรชีวิตของระบบ (Game Architecture) ในการสร้างกลไกเชิงโต้ตอบที่สามารถสื่อสารประเด็นทางสุขภาพจิตได้อย่างลึกซึ้ง
2. **เพื่อพัฒนาเกมคอมพิวเตอร์แนว 2.5 มิติ (2.5D):** พัฒนาเกมคอมพิวเตอร์ที่มีชื่อว่า "Depressonant" ที่จำลองประสบการณ์ทางอารมณ์ กลไกความเครียดสะสม และการตัดสินใจในชีวิตประจำวันของผู้เผชิญภาวะซึมเศร้า
3. **เพื่อประเมินประสิทธิภาพและความพึงพอใจของผู้ใช้งาน:** ทดสอบและประเมินผลการเรียนรู้ ความพึงพอใจ และการสร้างความเห็นอกเห็นใจ (Empathy) ของผู้เล่นที่มีต่อตัวเกม

## 1.6 ขอบเขตการศึกษา

### 1.6.1 ขอบเขตด้านเนื้อหาและโครงสร้างเกม
1. **การดำเนินเรื่องตามวันเวลา (Day Progression):** ดำเนินเรื่องราวเป็นระยะเวลา 14 วัน (และส่วนขยายสรุปผลรวมสูงสุด 17 วัน) โดยแบ่งการเล่าเรื่องออกเป็น 5 ช่วงหลัก (Phase 0 ถึง Phase 4 และบทสรุป Phase 5) ตามโครงสร้างจังหวะอารมณ์ (Pacing) ที่สะท้อนการก่อตัวของปัญหา จุดเปลี่ยน และการรับมือ
2. **ระบบฉากจบที่หลากหลาย (Multiple Endings):** ตัวเกมมีฉากจบหลัก 3 รูปแบบ ขึ้นอยู่กับค่าความเครียดสะสม (Stress Level) และเงื่อนไขการครอบครองไอเทมสำคัญ ได้แก่:
   * **Ending A (Good Ending - The Existence / The Sun After the Storm):** ค่าความเครียด 0–30 หน่วย และครอบครองไอเทมภาพวาดของเรน
   * **Ending B (Normal Ending - Fading Away / สมดุลชีวิตใหม่):** ค่าความเครียด 31–70 หน่วย
   * **Ending C (Bad Ending - ความมืดมิด):** ค่าความเครียด 71–100 หน่วย
   * **ฉากจบพิเศษ (Special Game Over):** เกิดขึ้นทันทีเมื่อผู้เล่นปล่อยให้ค่าความเครียดคงที่อยู่ที่ 100 หน่วยต่อเนื่องกันเป็นเวลา 2 วัน
3. **ปฏิสัมพันธ์กับตัวละคร (NPC Interaction):** มีตัวละครที่เกี่ยวข้องทั้งในครอบครัว โรงเรียน และชุมชนรวมกว่า 10 ตัวละคร ซึ่งมีบทสนทนาประจำวัน (Daily Dialogue) และบทสนทนาทางเลือกที่ส่งผลต่อค่าความเครียด

### 1.6.2 ขอบเขตด้านฟังก์ชันและระบบการทำงาน
1. **ระบบตัวแปรความเครียดระดับโลก (Global Stress System):** คำนวณค่าความเครียดระหว่าง 0–100 หน่วย ที่แปรผันตามการเลือกตอบบทสนทนา เหตุการณ์รายวัน และการใช้ไอเทม
2. **ระบบการตอบสนองเชิงภาพ (Visual Feedback & Vignette):** แสดงผลขอบจอมืดลง (Tunnel Vision Effect) และการสั่นไหวของหน้าจอเมื่อค่าความเครียดสูงขึ้น เพื่อถ่ายทอดสภาวะกดดันทางจิตใจ
3. **ระบบทางเลือกบทสนทนาแบบปิดกั้น (Stress-Locked Choices):** ตัวเลือกการตอบสนองเชิงวิกฤตจะถูกปิดกั้นหรือแสดงผลแบบบิดเบือน (Glitch Text) หากค่าความเครียดไม่ตรงตามเงื่อนไขที่กำหนด
4. **ระบบห้องนอนส่วนตัว 3 มิติ (3D Immersive Bedroom):** ห้องนอนในมุมมองบุคคลที่หนึ่ง (First-Person Perspective) สำหรับการปฏิสัมพันธ์กับสิ่งของ (เช่น ผ้าม่าน กระจกตรวจสภาวะจิต) และใช้เตียงนอนเป็นจุดบันทึกเกมและข้ามวัน
5. **ระบบคลังสิ่งของและไอเทม (Inventory System):** คลังเก็บไอเทมขนาด 6 ช่อง รองรับการใช้งานไอเทม 6 ชนิดที่มีคุณสมบัติแตกต่างกัน:
   * **ไดอารี่ (Diary):** แสดงบันทึกและค่าความเครียดพร้อม UI ที่เปลี่ยนสีตามอารมณ์
   * **หูฟัง (Headphones):** ใช้ลดค่าความเครียดได้ 10% (ใช้วันละ 1 ครั้งตั้งแต่ช่วงเปลี่ยนผ่าน)
   * **ลูกอม (Candy):** ใช้แล้วหมดไป ลดความเครียด 3 หน่วย
   * **นมสตรอว์เบอร์รี่ (Strawberry Milk):** ใช้แล้วหมดไป ลดความเครียด 5 หน่วย
   * **ปลอกแขน (Armband):** ไอเทมติดตัว ลดทอนผลกระทบจากความเครียดลงครึ่งหนึ่ง (ทำงานอัตโนมัติวันละ 1 ครั้ง)
   * **ภาพวาดของเรน (Rain's Drawing):** ไอเทมสำคัญ (Key Item) ที่ใช้ปลดล็อกฉากจบที่ดี
6. **ระบบติดตามเป้าหมายรายวัน (Daily Quest Tracker):** แสดงรายชื่อบุคคลสำคัญที่ตัวละครต้องเข้าพบในแต่ละวัน และซ่อนรายการเมื่อปฏิสัมพันธ์ครบถ้วน
7. **ระบบการควบคุม (Player Movement & Control):** รองรับการเคลื่อนที่ในสภาพแวดล้อม 2.5 มิติด้วยปุ่ม W, A, S, D การกด Shift เพื่อวิ่งเร็วขึ้น 2 เท่า การกลับภาพตัวละครแนวนอน (Horizontal Mirroring) ตามทิศทาง และการโต้ตอบด้วยปุ่ม E, F, Tab และ Esc

### 1.6.3 ขอบเขตด้านประชากรและกลุ่มตัวอย่าง
กลุ่มเป้าหมายในการทดสอบประสิทธิภาพและความพึงพอใจของเกม ประกอบด้วย นิสิตสาขาวิชาวิทยาการคอมพิวเตอร์ และบุคคลทั่วไปที่มีความสนใจในเกมดิจิทัลหรือประเด็นทางสุขภาพจิต **จำนวนรวมไม่น้อยกว่า 20 คน** โดยประเมินผ่านระบบแบบสอบถามออนไลน์ (Google Forms)

## 1.7 ซอฟต์แวร์และฮาร์ดแวร์ที่ใช้ในการดำเนินงาน

### 1.7.1 ซอฟต์แวร์ (Software)
* **Game Engine:** Unity Engine (เวอร์ชัน 2022 LTS / 6000) รองรับ Universal Render Pipeline (URP)
* **Code Editor:** Visual Studio Code ควบคู่กับ Unity C# Tools
* **Digital Art & 2D Asset:** Krita, Adobe Photoshop
* **Generative AI Tool:** Midjourney (สำหรับสร้างแนวคิดต้นแบบและโครงสร้างเฟรมแอนิเมชัน Sprite Sheet)
* **Audio Editor:** Audacity (ตัดต่อ ผสมเสียง และทำความสะอาดเสียง SFX/BGM)
* **Version Control:** Git และ GitHub สำหรับการประสานงานและจัดเก็บเวอร์ชันของซอร์สโค้ด

### 1.7.2 ฮาร์ดแวร์ (Hardware)
* หน่วยประมวลผล (CPU): Intel Core i5 / AMD Ryzen 5 ขึ้นไป
* หน่วยความจำหลัก (RAM): ขนาด 16.0 GB ขึ้นไป
* หน่วยประมวลผลกราฟิก (GPU): การ์ดจอแยกที่รองรับ DirectX 11 / OpenGL Core
* อุปกรณ์ควบคุม: แป้นพิมพ์ (Keyboard) และเมาส์ (Mouse)
* ระบบปฏิบัติการ: Microsoft Windows 10 / Windows 11 (64-bit)

## 1.8 แผนและขั้นตอนการดำเนินงาน
1. **ระยะวิเคราะห์และวางแผน (เดือนที่ 1–2):** กำหนดแนวคิด สตอรี่บอร์ด กลไกของเกม และออกแบบสถาปัตยกรรมระบบ
2. **ระยะพัฒนาต้นแบบ (Prototype) (เดือนที่ 3–4):** สร้างกลไกหลัก เช่น ระบบฟิสิกส์ 2.5D, ระบบบันทึกเกม, ระบบคำนวณความเครียด และการเคลื่อนที่
3. **ระยะพัฒนาส่วนสมบูรณ์และเนื้อหา (เดือนที่ 5–10):** สร้างฉาก 3 มิติ, สไปรต์ตัวละคร 2 มิติ, บทสนทนาครบทั้ง 14 วัน, ระบบไอเทม และเสียงประกอบ
4. **ระยะทดสอบ ปรับปรุง และสรุปผล (เดือนที่ 11–12):** ทดสอบประสิทธิภาพระบบ (Black Box Testing), เปิดให้กลุ่มตัวอย่างทดลองเล่น, เก็บรวบรวมผลการประเมิน และจัดทำรายงานวิจัยฉบับสมบูรณ์

## 1.9 ประโยชน์ที่คาดว่าจะได้รับ
1. ได้เกมคอมพิวเตอร์แนว 2.5 มิติ "Depressonant" ที่เป็นสื่อการเรียนรู้เชิงโต้ตอบที่มีคุณภาพและสามารถนำไปเผยแพร่ได้จริง
2. ผู้เล่นเกิดความตระหนักรู้ ความเข้าใจ และความเห็นอกเห็นใจ (Empathy) ต่อผู้เผชิญภาวะซึมเศร้าผ่านประสบการณ์จำลอง
3. เป็นแนวทางและองค์ความรู้ตัวอย่างในการประยุกต์ใช้เทคนิคกราฟิก 2.5 มิติ (การผสาน 2D Sprite เข้ากับสภาพแวดล้อม 3D ใน URP) สำหรับนักพัฒนาเกมรุ่นต่อไป
4. ได้สื่อกลางที่ช่วยลดช่องว่างความเข้าใจระหว่างผู้ป่วยโรคซึมเศร้ากับคนในครอบครัวและสังคม
