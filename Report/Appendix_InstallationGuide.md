# ขั้นตอนการติดตั้งและข้อกำหนดของระบบ (Installation Guide)

เอกสารนี้จัดทำขึ้นเพื่อให้คำแนะนำเกี่ยวกับความต้องการของระบบคอมพิวเตอร์ และขั้นตอนการติดตั้งเพื่อเปิดเล่นเกม "Depressonant (ดีเพรสโซแนนท์)" บนระบบปฏิบัติการ Windows

---

## 1. ความต้องการของระบบ (System Requirements)

เพื่อให้ตัวเกมสามารถประมวลผลระบบ 2.5D, Universal Render Pipeline (URP) และเอฟเฟกต์ Vignette ได้อย่างราบรื่น เครื่องคอมพิวเตอร์ควรมีคุณสมบัติตามเกณฑ์ดังนี้:

| รายการ | สเปกขั้นต่ำ (Minimum Requirements) | สเปกที่แนะนำ (Recommended Requirements) |
| :--- | :--- | :--- |
| **ระบบปฏิบัติการ (OS)** | Windows 10 (64-bit) | Windows 10 / Windows 11 (64-bit) |
| **หน่วยประมวลผล (CPU)** | Intel Core i3 (Gen 6 ขึ้นไป) หรือ AMD Ryzen 3 | Intel Core i5 (Gen 8 ขึ้นไป) หรือ AMD Ryzen 5 |
| **หน่วยความจำหลัก (RAM)** | 4.0 GB | 8.0 GB - 16.0 GB |
| **การ์ดจอ (GPU)** | Intel UHD Graphics 620 หรือเทียบเท่า | NVIDIA GeForce GTX 1050 / AMD Radeon RX 560 ขึ้นไป |
| **DirectX** | Version 11 | Version 11 หรือ 12 |
| **พื้นที่จัดเก็บข้อมูล (Storage)** | พื้นที่ว่างอย่างน้อย 2.0 GB (HDD/SSD) | พื้นที่ว่างอย่างน้อย 4.0 GB (SSD แนะนำ) |
| **อุปกรณ์ควบคุม** | แป้นพิมพ์ (Keyboard) และเมาส์ (Mouse) | แป้นพิมพ์ (Keyboard) และเมาส์ (Mouse) |

---

## 2. ขั้นตอนการติดตั้งและเข้าเล่นเกม (สำหรับผู้ใช้งานทั่วไป)

ตัวเกม "Depressonant" ได้รับการคอมไพล์เป็นแพ็กเกจแบบ Standalone Executable ทำให้ผู้ใช้สามารถเปิดเล่นได้ทันทีโดยไม่จำเป็นต้องติดตั้งโปรแกรมเสริม มีขั้นตอนดังนี้:

### ขั้นตอนที่ 1: การดาวน์โหลดและแตกไฟล์
1. ดาวน์โหลดไฟล์บีบอัดของตัวเกม เช่น `Depressonant_Build_v1.0.zip`
2. คลิกขวาที่ไฟล์ `.zip` แล้วเลือก **"Extract All..." (แตกไฟล์ทั้งหมด)** หรือใช้โปรแกรม 7-Zip / WinRAR
3. เลือกตำแหน่งโฟลเดอร์ปลายทางที่ต้องการติดตั้ง (แนะนำให้วางในโฟลเดอร์ที่ไม่ใช่โฟลเดอร์ระบบ เช่น `D:\Games\Depressonant`)

### ขั้นตอนที่ 2: การเปิดเล่นเกม
1. เข้าไปในโฟลเดอร์ที่แตกไฟล์ไว้ จะพบโครงสร้างไฟล์ดังนี้:
   * 📁 `Depressonant_Data/` (โฟลเดอร์บรรจุทรัพยากรเกม)
   * 📄 `UnityCrashHandler64.exe`
   * 📄 `UnityPlayer.dll`
   * 🎮 **`Depressonant.exe`** (ไฟล์เปิดเกมหลัก)
2. ดับเบิ้ลคลิกที่ไฟล์ **`Depressonant.exe`** เพื่อเริ่มเกม
3. *(คำแนะนำ)* หากระบบ Windows Defender หรือ Antivirus แจ้งเตือน ให้คลิก **"More info" ➔ "Run anyway"** เพื่ออนุญาตให้เปิดเกม

## 3. ขั้นตอนการ Build เกมจาก Unity Editor (สำหรับนักพัฒนาและผู้ตรวจโครงงาน)

หากต้องการคอมไพล์โปรเจกต์จากซอร์สโค้ดใน Unity Editor:
1. เปิดโปรเจกต์ด้วย **Unity Editor (เวอร์ชัน 2022.3 LTS หรือสูงกว่า)**
2. ไปที่แถบเมนูด้านบน เลือก `File` ➔ `Build Settings...` (หรือกด `Ctrl + Shift + B`)
3. ตรวจสอบในช่อง **Scenes in Build** ให้แน่ใจว่าได้เรียงลำดับฉากสำคัญครบถ้วน:
   * `0: MainMenu`
   * `1: Bedroom_3D`
   * `2: Home`
   * `3: OutSide`
   * `4: School`
   * `5: Ending_Good`
   * `6: Ending_Normal`
   * `7: Ending_Bad`
   * `8: GameOver_Stress`
4. ที่ช่อง **Platform** เลือกเป็น `PC, Mac & Linux Standalone`
   * **Target Platform:** `Windows`
   * **Architecture:** `x86_64` (64-bit)
5. กดปุ่ม **Build** เลือกโฟลเดอร์ปลายทาง แล้วรอระบบคอมไพล์จนเสร็จสมบูรณ์

## 4. การแก้ไขปัญหาเบื้องต้น (Troubleshooting)

* **ปัญหาที่ 1: เปิดเกมแล้วขึ้นจอดำหรือไม่ตอบสนอง**
  * *วิธีแก้:* อัปเดตไดรเวอร์การ์ดจอ (NVIDIA / AMD / Intel) ให้เป็นเวอร์ชันล่าสุด และติดตั้ง Microsoft Visual C++ Redistributable (2015–2022)
* **ปัญหาที่ 2: ภาพกระตุกหรือไม่ลื่นไหล**
  * *วิธีแก้:* เข้าเมนู `Options` ภายในเกม ปรับลดค่า `Graphic Quality` หรือปรับความละเอียดหน้าจอ (Resolution) ลงมาที่ 1920x1080 หรือ 1280x720
* **ปัญหาที่ 3: ตัวหนังสือภาษาไทยแสดงเป็นกล่องสี่เหลี่ยมหรือฟอนต์ไม่ขึ้น**
  * *วิธีแก้:* ตรวจสอบว่าไฟล์ในโฟลเดอร์ `Depressonant_Data` อยู่ครบถ้วน และไม่ได้มีการเปลี่ยนชื่อไฟล์หรือแยกโฟลเดอร์ออกจากตัวเกม
