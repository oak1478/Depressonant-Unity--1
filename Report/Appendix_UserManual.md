# ภาคผนวก ข
# คู่มือการใช้งานและการเล่นเกม (User Manual & Gameplay Guide)

คู่มือฉบับนี้จัดทำขึ้นเพื่อแนะนำระบบการเล่น กลไกการควบคุม และฟังก์ชันต่างๆ ภายในเกม "Depressonant (ดีเพรสโซแนนท์)" สำหรับผู้เล่นและคณะกรรมการประเมินผล

---

## 1. การควบคุมพื้นฐาน (Keyboard & Mouse Controls)

ตัวเกมใช้ระบบการควบคุมที่ผสมผสานระหว่างมุมมองบุคคลที่หนึ่ง (ในห้องนอน) และมุมมอง 2.5 มิติ (ในฉากทั่วไป) ดังนี้:

### ตารางการควบคุม (Control Layout):
| ปุ่มกด (Keys) | การกระทำในมุมมอง 2.5D (Home, Outside, School) | การกระทำในมุมมองบุคคลที่หนึ่ง (ห้องนอน 3D) |
| :---: | :--- | :--- |
| **W** | เดินขึ้นด้านบน (หันขวาตามทิศทาง) | เดินไปข้างหน้า |
| **S** | เดินลงด้านล่าง (หันซ้ายตามทิศทาง) | เดินถอยหลัง |
| **A** | เดินไปทางซ้าย (หันซ้าย) | เดินสไลด์ไปทางซ้าย (Strafe Left) |
| **D** | เดินไปทางขวา (หันขวา) | เดินสไลด์ไปทางขวา (Strafe Right) |
| **Shift (ค้าง)** | **วิ่งเร็วขึ้น 2 เท่า (Sprint)** | วิ่งเร็วขึ้น |
| **E / Spacebar / Enter** | เริ่มบทสนทนากับตัวละคร NPC ที่อยู่ใกล้ | - |
| **F** | โต้ตอบกับไอเทม / เก็บไอเทมเข้าคลัง | โต้ตอบกับสิ่งของ (ส่องกระจก, เปิดม่าน, เข้านอน) |
| **Tab** | **เปิด / ปิด หน้าต่างคลังไอเทม (Inventory Bag)** | - |
| **เมาส์คลิกซ้าย** | เลือกคำตอบบทสนทนา / กดใช้งานไอเทมในคลัง | หมุนมุมกล้องมองรอบห้องนอน 3D |
| **Esc** | เปิดเมนูตั้งค่า (Options) หรือออกจากเกม | เปิดเมนูตั้งค่า / ออกจากเกม |

## 2. ส่วนติดต่อผู้ใช้และสัญญาณบอกสถานะ (HUD & Visual Indicators)

1. **เอฟเฟกต์ขอบจอดำ (Vignette - Tunnel Vision):**
   * **ขอบจอปกติ/สว่าง:** ค่าความเครียดต่ำ (สุขภาพจิตคงที่)
   * **ขอบจอดำคล้ำบีบแคบเข้ามา:** ค่าความเครียดสูง (ระวัง! หากความเครียดเต็ม 100 ติดต่อกัน 2 วัน เกมจะจบลงทันที)
2. **แถบติดตามเป้าหมายประจำวัน (Daily Quest Tracker):**
   * แสดงอยู่บริเวณมุมของหน้าจอ แสดงรายชื่อบุคคลที่เนียควรไปพบหรือพูดคุยในวันนั้นๆ
   * เมื่อเดินไปพูดคุยสำเร็จ รายชื่อจะถูกขีดฆ่าหรือหายไปจากรายการ
   * เมื่อคุยครบทุกคน ข้อความจะขึ้นเตือนว่า *"พูดคุยครบแล้ว!"* และผู้เล่นสามารถกลับไปเข้านอนเพื่อข้ามวันได้

## 3. คู่มือการใช้งานระบบห้องนอน 3 มิติและการข้ามวัน (3D Bedroom & Progression)

ห้องนอนของเนียเป็นจุดเริ่มต้นของแต่ละวัน และเป็นพื้นที่เซฟโซนส่วนตัว:
* 🪞 **กระจกเงา (Mirror):** เดินเข้าไปเล็งจุดกึ่งกลางจอแล้วกดปุ่ม `F` เพื่อส่องกระจก เนียจะแสดงความคิดสะท้อนในจิตใจ ช่วยให้ผู้เล่นประเมินระดับความเครียดปัจจุบันได้
* 🪟 **ผ้าม่าน (Curtain):** กด `F` เพื่อเปิดรับแสงแดดยามเช้า หรือปิดม่านเพื่อสร้างความสงบ
* 🛏️ **เตียงนอน (Bed):**
  * เมื่อทำกิจกรรมประจำวันครบถ้วน ให้เดินมาที่เตียงนอนแล้วกดปุ่ม `F` (หรือ `E`)
  * ระบบจะสั่ง **บันทึกข้อมูลเกมลงในเซฟอัตโนมัติ (Auto-Save)** และตัดเข้าสู่หน้าจอเปลี่ยนผ่านไปยังเช้าของวันถัดไปทันที

## 4. คู่มือการใช้งานคลังไอเทมและคุณสมบัติไอเทมทั้ง 6 ชนิด

กดปุ่ม **`Tab`** เพื่อเปิดหน้าต่างกระเป๋าของเนีย (Nia's Bag) คลิกเมาส์ที่ไอเทมเพื่อดูคำอธิบาย และกดปุ่ม **"ใช้งาน (Use)"**:

1. 📓 **ไดอารี่ (Diary):**
   * *วิธีใช้:* กดใช้เพื่อเปิดหน้าต่างบันทึกเรื่องราว
   * *คุณสมบัติพิเศษ:* พื้นหลังและฟอนต์ตัวหนังสือของไดอารี่จะเปลี่ยนสีและรูปแบบไปตามอารมณ์ของเนีย และหากมีไดอารี่ในกระเป๋า จะมีตัวเลขแสดงค่าความเครียด (%) ให้เห็นบนหน้าจอ
2. 🍬 **ลูกอม (Candy):**
   * *วิธีใช้:* ไอเทมบริโภค (ใช้แล้วหมดไป)
   * *คุณสมบัติพิเศษ:* ช่วยลดค่าความเครียดทันที 3 หน่วย
3. 🥛 **นมสตรอว์เบอร์รี่ (Strawberry Milk):**
   * *วิธีใช้:* ไอเทมบริโภค (ใช้แล้วหมดไป)
   * *คุณสมบัติพิเศษ:* ช่วยลดค่าความเครียดทันที 5 หน่วย
4. 🎧 **หูฟัง (Headphones):**
   * *วิธีใช้:* ไอเทมกดใช้ (ไม่หายไป)
   * *คุณสมบัติพิเศษ:* ปลดล็อกใช้งานได้ตั้งแต่ช่วงวันที่ 8 เป็นต้นไป กดใช้เพื่อฟังเพลงตัดเสียงรบกวนภายนอก ช่วยลดความเครียดได้ 10% (จำกัดสิทธิ์ใช้วันละ 1 ครั้ง และจะรีเซ็ตสิทธิ์ใหม่ในเช้าวันถัดไป)
5. 🎗️ **ปลอกแขน (Armband):**
   * *วิธีใช้:* ไอเทมติดตัว (Passive Item) ไม่จำเป็นต้องกดใช้
   * *คุณสมบัติพิเศษ:* ทำงานอัตโนมัติวันละ 1 ครั้งเมื่อเนียได้รับความเครียด โดยจะช่วยดูดซับและลดทอนความเครียดที่เพิ่มขึ้นลง 50%
6. 🖼️ **ภาพวาดของเรน (Rain's Drawing):**
   * *วิธีใช้:* ไอเทมเนื้อเรื่องสำคัญ (Key Item) ได้รับจากน้องสาว
   * *คุณสมบัติพิเศษ:* เป็นสัญลักษณ์ของความผูกพันในครอบครัว จำเป็นต้องเก็บรักษาไว้ในกระเป๋าเพื่อใช้เป็นเงื่อนไขปลดล็อก Good Ending ในวันตัดสิน

## 5. กลยุทธ์การเล่นเพื่อมุ่งสู่ฉากจบที่ดี (Walkthrough Strategy)

* **การประคองความเครียด:** ในช่วงบทสนทนา ให้พิจารณาตอบอย่างระมัดระวัง ไม่ตอบโต้ด้วยความก้าวร้าวหรือยอมจำนนอย่างไร้เหตุผล และไม่เก็บกดอารมณ์จนมืดมิด
* **การใช้ไอเทมอย่างคุ้มค่า:** เก็บลูกอมและนมสตรอว์เบอร์รี่ไว้ใช้ในวันที่เผชิญการสอบหรือความกดดันสูงในโรงเรียน
* **เงื่อนไขฉากจบแห่งความหวัง (Good Ending):**
  1. รักษาค่าความเครียดสะสมเมื่อถึงวันสุดท้ายให้อยู่ในเกณฑ์ **ไม่เกิน 30 หน่วย**
  2. ต้องมีไอเทม **ภาพวาดของเรน (Rain's Drawing)** ติดอยู่ในกระเป๋า
  3. เนียจะสามารถก้าวข้ามความเจ็บปวด ค้นพบการยอมรับในตนเอง และมองเห็นแสงตะวันหลังมรสุมร้ายได้อย่างงดงาม
